## 问题现象与调研

官方安装包仅含英文界面。上游为原生 AppKit / SwiftPM 项目，许多文字直接绘制，需要在实际文字显示位置接入语言资源，不能只增加一个语言目录。

官方主分支已经增加后续功能，因此选择发布标签 v0.2.0（提交 28da5fd）制作中文版本，避免把新功能与此次汉化混在一起。来源为 https://github.com/current/wisp.git，MIT 许可证保留在程序资源中。

## 修改方案

- 为页面、菜单、设置、状态、帮助及确认提示接入简体中文与英文资源，共 1008 条资源、979 个代码模板。
- 插入的程序名、项目名、端口、PID、路径和命令保持原值；系统字段、枚举标识、图标名、扫描路径继续使用原始标识。
- 语言与资源加载结果按进程缓存，避免实时绘制时重复读取。
- 打包脚本增加独立预览版本，将语言资源与许可文件一并装入程序。
- 修正当前 Swift 编译器下 StorageIndex 的同名局部变量遮蔽，需要显式引用 self.generation 才能编译。
- 调整个别详情标题与说明之间的间距，保持原有布局和操作流程。

## 排查中发现的关键问题

1. SwiftPM 会将语言目录规范化为 `zh-hans.lproj`。按大小写敏感的资源名查找 `zh-Hans` 会返回空，导致仍显示英文；现在按资源包实际语言目录匹配，并测试打包后的独立程序。
2. 本地化不能改写存储扫描路径或 launchd 的字段名，也不能改变依赖英文标识的统计周期。相关标识保持稳定，显示时才翻译，并增加路径保护测试。
3. 程序自带的离屏截图无法完整捕获部分滚动区域，不能作为最终视觉证据。改用前台独立程序的窗口捕获与实际点击完成验收；离屏截图代码未做额外改造。

## 维护与重建

源码分支：`codex/zh-hans-0.2.0`。本次修改未提交 Git、未推送或发布。

在项目根目录运行：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/localization_audit.py --check
WISP_LANGUAGE=en swift test --jobs 2
WISP_LANGUAGE=zh-Hans swift test --jobs 2 --filter LocalizationTests
scripts/build-app.sh --native --preview
```

后续增补翻译应同时更新两份 Localizable.strings，并保持所有插值和格式符一致。预览版未替代原版权限或登录项；如将来正式替换，应另行确认安装与数据沿用方案。
